# Research: S028 candidate freeze

## Decision: One exact current stable contract

Promote current software/schema/model dispatch to exact 1.1.0. Historical 1.0.0 remains selected by its byte-identical bundled released resource and version-specific semantics. Unreleased development identity is unsupported after promotion. Alternatives (identity rewriting, approximate selection or indefinite dev adapter) contradict the ratified exact registry.

## Decision: Preserve observations and promote official capabilities

Keep precise schema_only and experimental native input tuples, add complete stable native tuple, and emit stable only from official new encode/private conversion targets. Lower declarations remain observations, not installed capability. Reject contradictory booleans and OCR requirements.

## Decision: Strengthen the existing stable package verifier

Existing stable loadRepositorySchemas already checks canonical/immutable identity and equality. Switch config/workflow to it rather than adding a mode. Version/schema-only host probes are insufficient for #65; exercise four-format native command workflows and historical command input using matching packaged binaries. Verify public v1.0.0 consumer bytes by known release checksum/source and execute fresh current-output rejection. Preserve CREATE_NO_WINDOW/noninteractive behavior.

Observed published inspect diagnostics contain only input validation failure. The proof therefore uses an immediately preceding validate call on the same unchanged payload to discriminate exact 1.0.0 schema identity rejection for each owning command, then independently verifies runtime/no-publication refusal. This narrow adjustment preserves the required incompatibility and safety gate without inventing diagnostics the released binary does not emit. Evidence counts 32 identity probes and 32 owning refusal paths separately.

Maintained docs contain stale conversion/discovery deferrals and ASS/SSA capability contradictions after S026/S027. Fix these, add authored ASS/SSA preview route and derive nested format navigation from its governed map, but retain released v1.0.0 downloads and two immutable public schema allowlist entries until #67. Publication-ready v1.1.0 notes stay repository-authored.
