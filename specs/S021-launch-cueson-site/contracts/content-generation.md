# Content Generation Contract

## Authority

`README.md`, `CONTRIBUTING.md`, `SECURITY.md`, `CHANGELOG.md`, and maintained files under root `docs/` remain authored source. Files beneath `site/content/generated/`, selected files beneath `site/public/assets/`, versioned files beneath `site/public/schema/`, and `site/public/deployment.json` are disposable build outputs.

## Inputs

The generator reads only paths declared in `site/content-map.json`, the two immutable schema paths declared there, the approved Cueson 1.0.0 brand paths declared there, the brand import manifest used to validate approved source hashes, and the selected repository commit supplied by the build or resolved with a hidden non-interactive Git child process.

## Output rules

- Every generated MDX file starts with controlled `title`, `description`, and `source` front matter, followed by the authoritative source body.
- Known documentation links are rewritten to their public routes. External links, code spans, code fences, and non-document repository links remain intact.
- Every generated and copied path is checked against its declared output root; traversal, absolute filesystem paths, duplicates, and case-folding collisions fail generation.
- Brand and schema copies use byte-copy operations and are checked against source SHA-256 after writing.
- Schema output paths are exactly `/schema/v0.0.0/cueson.schema.json` and `/schema/v1.0.0/cueson.schema.json`; no output contains a `latest` schema path.
- The content manifest sorts every record by public route or output path and contains no timestamp, machine path, hostname, username, or other local identity.
- Generation replaces only the declared disposable output trees and never edits an authoritative source.

## Drift check

`generate --check` performs no writes. It recomputes mappings, source hashes, expected transformed bytes, output hashes, copied-byte identity, and commit metadata. It fails when an output is missing, extra, stale, corrupted, or generated by a different mapping or generator version.

## Failure contract

A failure reports the logical source or public path and the violated rule. It must not print secrets or machine-local absolute paths in committed or uploaded evidence.
