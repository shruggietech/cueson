# Data Model: Launch cueson.io

## AuthoritativeDocument

| Field | Type | Rules |
|------|------|-------|
| `source_path` | repository-relative path | Unique, portable, inside an approved root documentation location |
| `route_slug` | string array | Unique public documentation route, no traversal or empty segment |
| `title` | string | Non-empty public title |
| `description` | string | Non-empty public metadata description |
| `order` | integer | Stable navigation order |
| `source_sha256` | lowercase hex | Derived from exact source bytes |

## GeneratedAdaptation

| Field | Type | Rules |
|------|------|-------|
| `output_path` | site-relative path | Must remain under `site/content/generated/` |
| `source_path` | repository-relative path | References one AuthoritativeDocument |
| `route` | absolute path | Derived from `route_slug` under `/docs/` |
| `output_sha256` | lowercase hex | Derived from exact generated bytes |
| `generator_version` | integer | Changes when transformation behavior changes |

GeneratedAdaptation is disposable. It is valid only when its source hash, output hash, mapping, and generator version all match a fresh computation.

## BrandWebAsset

| Field | Type | Rules |
|------|------|-------|
| `source_path` | repository-relative path | Must identify an approved file inside `brand/cueson/1.0.0/kit/` |
| `public_path` | absolute path | Unique target below `/assets/` |
| `sha256` | lowercase hex | Must match the imported brand manifest and generated copy |
| `purpose` | enum | `logo`, `social_preview`, `favicon`, or `font` |

## ReleasedSchema

| Field | Type | Rules |
|------|------|-------|
| `version` | semantic version | Exactly `0.0.0` or `1.0.0` in this slice |
| `source_path` | repository-relative path | Immutable file below `schema/releases/v{version}/` |
| `public_path` | absolute path | `/schema/v{version}/cueson.schema.json` |
| `bytes` | integer | Exact source length |
| `sha256` | lowercase hex | Exact source digest |
| `media_type` | string | JSON media type with UTF-8 semantics |

ReleasedSchema transitions from repository-only to publicly resolving, but its bytes and identity never transition.

## PublicRoute

| Field | Type | Rules |
|------|------|-------|
| `path` | absolute path | Unique and trailing-slash canonicalized |
| `kind` | enum | `landing`, `documentation`, `schema`, `asset`, `not_found`, or `redirect` |
| `status` | integer | Expected 200, 308, or 404 |
| `title` | string or null | Required for indexable HTML pages |
| `description` | string or null | Required for indexable HTML pages |
| `canonical_url` | URL or null | Apex URL for indexable HTML pages |
| `source_ref` | path or entity key | Traces the route to its authority |

## DeploymentArtifact

| Field | Type | Rules |
|------|------|-------|
| `commit` | 40-character lowercase Git SHA | Must be reachable from selected `main` and equal the checked-out revision |
| `site_manifest_sha256` | lowercase hex | Digest of the sorted public file inventory |
| `route_count` | integer | Matches the verified route contract |
| `schema_digests` | map | Exactly the ReleasedSchema version-to-hash mapping |
| `generated_at` | absent | Timestamps are excluded to preserve deterministic output |

## DomainBinding

| Field | Type | Rules |
|------|------|-------|
| `zone_id` | Cloudflare identifier | Exact `cueson.io` zone |
| `worker_name` | string | `cueson-site` |
| `hostname` | domain | Exactly `cueson.io` or `www.cueson.io` |
| `role` | enum | `origin` for apex, `redirect` for `www` |
| `dns_record_id` | provider identifier | Read back after Custom Domain creation |
| `certificate_state` | provider state | Must become active before success |

## VerificationRecord

| Field | Type | Rules |
|------|------|-------|
| `commit` | Git SHA | References one DeploymentArtifact |
| `checks` | ordered results | Build, unit, browser, artifact, DNS, TLS, HTTP, redirect, download, and schema checks |
| `cloudflare_before` | bounded inventory | Zone, relevant DNS, Worker, and redirect state before mutation |
| `cloudflare_after` | bounded inventory | Same fields read back after mutation |
| `result` | enum | `passed` or `failed`; partial success is never coerced to passed |

## Relationships

- One AuthoritativeDocument produces one GeneratedAdaptation.
- Many GeneratedAdaptations and BrandWebAssets contribute to one DeploymentArtifact.
- Each ReleasedSchema contributes one byte-exact public file and one PublicRoute.
- One DeploymentArtifact is served by two DomainBindings.
- One VerificationRecord proves one DeploymentArtifact and both DomainBindings.
