# Cueson v1.1.0

- Add bounded UTF-8 ASS v4+/SSA v4 detection, source-preserving native ingest and deterministic textual model rendering, retaining ordered styles, events, overrides, karaoke, drawings and inert attachments alongside exact original source bytes.
- Complete all twelve conversion directions among SubRip, WebVTT, ASS and SSA, with explicit native-owner losses, deterministic defaults, checked centisecond precision and strict/fatal refusal before output publication.
- Extend CLI discovery and privacy-safe inspection, hostile-input/fuzz conformance and native platform proof. Six pure-Go packages include identical immutable schema and legal files, checksums and target-bound SPDX JSON SBOMs.

Exact historical 1.0.0 Cue JSON uses the bundled immutable schema and version-specific semantics. Every new encode uses exact 1.1.0; released v1.0.0 consumers reject this output, including SubRip/WebVTT documents. There is no historical-output selector. Exact-current schema-only and complete experimental input observations remain unchanged when loaded.

Exact restoration reproduces original bytes. Rendering and conversion do not claim byte or pixel equivalence. The bounded profile does not load external resources, execute attachments, rasterize drawings/fonts, accept legacy ASS/SSA codepages or add OCR/other format families. Packages are unsigned and unattested. Public schema/site hosting remains a separately authorized outcome.
