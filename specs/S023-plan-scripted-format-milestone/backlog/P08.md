## Outcome

Validated scripted native models render deterministically while exact restoration remains an independent operation.

## Context

Parsing preserves native structure; rendering must honor edits and retained unknown information without substituting the source envelope as output.

## Scope

Implement both native renderers and version-aware model checks using [#53](https://github.com/shruggietech/cueson/issues/53) edit ownership, serialization, timing, attachment/reference, and retained-content rules.

## Acceptance criteria

- [ ] Each accepted renderable unedited model renders to reparsable native syntax with equivalent required native/common semantics; retained malformed models refuse rendering before output publication in every mode.
- [ ] Edits to owned model fields appear in output and are not overwritten by stale raw source representations.
- [ ] Unknown sections/fields, style/event ordering, raw overrides, non-dialogue content, drawings, and attachments follow the agreed retention contract.
- [ ] Unsafe or ambiguous models fail before output publication, and deterministic serialization follows the agreed encoding and timing policy.
- [ ] Rendering does not claim source-byte identity; exact restore still uses verified original assets.
- [ ] Both scripted variants and existing SubRip/WebVTT render behavior pass their corpus cycles.

## Dependencies

Native blockers: [#58](https://github.com/shruggietech/cueson/issues/58). Coordination across the same implementation slice does not add reciprocal dependencies. Protected release/tag and production transitions require their own explicit operator authority.

## Verification

Run ingest-render-ingest semantic cycles, edited-model tests, invalid-model and no-partial-publication tests, exact-restore separation, and native CI.
