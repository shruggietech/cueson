## Outcome

Scripted timed dialogue can convert to both existing text targets with explicit semantic degradation reporting.

## Context

Style, layout, karaoke, drawings, attachments, and non-dialogue content cannot all be represented by SubRip or WebVTT.

## Scope

Add the four outbound source-target pairs through the existing private projection and deterministic loss-report boundary. Ratify new stable loss codes without changing old meanings.

## Acceptance criteria

- [ ] Baseline readable dialogue and representable timing/shared emphasis convert correctly to each target.
- [ ] Every omitted or degraded native feature has a complete atomic loss entry with stable code and portable source reference.
- [ ] Drawing-only events and unrepresentable semantics are handled by explicit contract policy rather than invented text.
- [ ] Strict mode refuses all known loss before publication; fatal incompatibilities fail in both modes.
- [ ] Permissive conversion never labels a lossy result lossless, never uses source restoration as conversion, and never leaks caller identity.
- [ ] Existing SubRip/WebVTT pair behavior and loss vocabulary remain compatible.

## Dependencies

Native blockers: [#59](https://github.com/shruggietech/cueson/issues/59). Coordination across the same implementation slice does not add reciprocal dependencies. Protected release/tag and production transitions require their own explicit operator authority.

## Verification

Run all four direction goldens, semantic target reparse, complete-loss ordering, strict destination-preservation, limits, privacy, and old-conversion regressions.
