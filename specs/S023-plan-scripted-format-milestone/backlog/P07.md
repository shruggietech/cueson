## Outcome

Both scripted formats encode to valid Cue JSON with exact source capture and usable timed dialogue semantics.

## Context

[#53](https://github.com/shruggietech/cueson/issues/53)/[#56](https://github.com/shruggietech/cueson/issues/56) define native and common representations; [#57](https://github.com/shruggietech/cueson/issues/57) supplies the fidelity evidence.

## Scope

Extend the bounded codec registry and content-first detector, reuse the shared exact source acquisition, and implement native ingest for the accepted ASS/SSA contracts. Keep common projection derived and preserve native structures.

## Acceptance criteria

- [ ] Both formats are selected from content with tested aliases, conflicting extensions, ambiguous signatures, and explicit format requests.
- [ ] All required accepted corpus rows produce schema-valid and semantically valid documents with truthful capability declarations.
- [ ] Sections, declared fields, events, styles, unknown occurrences, attachments/references, raw payloads, and native timings retain their specified fidelity.
- [ ] Common dialogue, speakers, line semantics, and supported karaoke tokens follow [#53](https://github.com/shruggietech/cueson/issues/53); drawings are never presented as native readable text.
- [ ] Malformed or unsupported cases have deterministic diagnostics or rejection without invented capability; parsing and allocation limits are enforced.
- [ ] Every accepted input restores byte-for-byte from its source envelope and no input path or local machine identity is serialized.

## Dependencies

Native blockers: [#55](https://github.com/shruggietech/cueson/issues/55), [#57](https://github.com/shruggietech/cueson/issues/57). Coordination across the same implementation slice does not add reciprocal dependencies. Protected release/tag and production transitions require their own explicit operator authority.

## Verification

Run codec unit and conformance tests, exact restoration, corpus projections, detection ambiguity cases, malformed and complexity boundaries, and all old-format regressions.
