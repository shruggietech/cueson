## Outcome

ASS and SSA have an implementation-ready, testable contract that preserves their native structures without overstating semantic or visual support.

## Context

The working roadmap identifies sections, styles, events, overrides, positioning, and karaoke timing. A generic text projection alone does not constitute this richer native contract.

## Scope

Define accepted ASS and SSA versions, canonical keys and aliases, encoding policy, ordered section and field structures, native timing, common dialogue projection, rendering ownership, malformed-input behavior, limits, and diagnostics. Set explicit policy for attachments, unknown sections, path-valued source metadata, and non-text drawing events.

## Acceptance criteria

- [ ] The contract distinguishes SSA and ASS layouts and dynamic Format declarations, including commas in dialogue text and unknown or duplicate occurrences.
- [ ] Original bytes remain authoritative; unknown source content and raw fields have a documented retention strategy, while runtime input paths and machine identities cannot enter Cue JSON.
- [ ] Speaker names, line-break and wrapping semantics, overrides, karaoke timing, drawings, layers, styles, and positioning have explicit native and derived treatment.
- [ ] Accepted embedded attachments are retained without loading, installing, or executing them; prohibited external-resource, path, identity, and active-content metadata cause whole-operation rejection without sanitizing source content.
- [ ] A source-linked conformance matrix states supported, preserved-only, malformed, and rejected cases, plus deterministic diagnostics and bounded complexity.
- [ ] Model-driven rendering has an explicit round-trip and edit-ownership contract; pixel rendering and video processing are outside this release.

## Dependencies

Native blockers: [#52](https://github.com/shruggietech/cueson/issues/52). Coordination across the same implementation slice does not add reciprocal dependencies. Protected release/tag and production transitions require their own explicit operator authority.
