## Outcome

The documented four-format conversion matrix has deliberate behavior for every supported distinct-format pair.

## Context

New native target renderers allow text-to-scripted projection; ASS/SSA variant differences need separate loss analysis.

## Scope

Add SubRip/WebVTT to ASS/SSA and ASS-to-SSA/SSA-to-ASS through the existing conversion boundary. Specify deterministic target style/script defaults and timing quantization without inventing source provenance.

## Acceptance criteria

- [ ] All six new directions have explicit supported, lossy, or fatal acceptance rows; unsupported edges are not advertised.
- [ ] Target defaults are deterministic and documented; target timing precision never silently truncates source timing.
- [ ] Style, override, alignment, event, and variant differences produce complete losses or explicit rejection as required.
- [ ] Supported loss-free baselines preserve text and timing semantics; target-native output reparses to the expected projection.
- [ ] Strict mode and fatal rejection preserve selected destinations and publish no payload.
- [ ] Together with [#60](https://github.com/shruggietech/cueson/issues/60) and the two existing directions, the release has a verified 12-direction matrix, or an explicitly ratified narrower release scope.

## Dependencies

Native blockers: [#60](https://github.com/shruggietech/cueson/issues/60). Coordination across the same implementation slice does not add reciprocal dependencies. Protected release/tag and production transitions require their own explicit operator authority.

## Verification

Run six direction goldens, target-native semantic reparse, precision-boundary cases, style/default determinism, strict/fatal publication checks, and full conversion matrix regressions.
