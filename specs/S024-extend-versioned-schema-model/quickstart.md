1. Run go test -count=1 ./internal/schema ./internal/model for exact identity, annotation, scripted shape/projection/reference/privacy and historical semantics proof.
2. Run go test -count=1 ./internal/cli ./internal/source ./internal/convert for old-input five-command matrix, source integrity, restoration, strict losses and no-publication behavior.
3. Run go test -count=1 ./... and the discovered nested module checks, existing fuzz budgets, vet, static analysis, vulnerability and six-target build checks.
4. Compare current schema emission/version with canonical1.1.0-dev; verify both immutable released hashes and embedded historical1.0.0 byte equality.
5. Run complete site lint/generation/unit/build/browser/artifact/dry-run proof. Public released schema routes and production remain unchanged.
6. Run repository authored-text formatter, documentation verifier, UTF-8/mojibake and git whitespace checks.
7. Confirm hosted CI/security/packaged proof and every review finding are satisfied on the official PR head.
