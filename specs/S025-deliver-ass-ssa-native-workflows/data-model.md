# S025 data model

The S024 typed scripted document remains the authoritative representation. No original path or machine identity is added.

## Captured native document

A dialect owns ordered sections/records with physical position-based IDs. Each style/event references one record and the active declaration. Attachments reference positive contiguous encoded-data ranges in their section. Raw header/line/time lexemes are truthful source observations and stay immutable under edits.

## Common dialogue

Only Dialogue events own common cues. Positive millisecond intervals must be exactly centisecond-representable for native rendering. Native Text controls raw payload and derived lines/plain text/spans/tags; actor fields yield native provenance. Eligible karaoke tokens are sequential, within the cue interval, and recomputed for coherent timing edits. Drawing-only dialogue retains a cue with empty readable text.

## Declaration state

Each style/event section starts without an active declaration. Complete Format records define field order and names, including bounded inert unknown additions. Malformed declarations reset usable state and are retained only when safe; subsequent Dialogue without a valid declaration rejects. Constructed complete owners may trigger canonical declarations while preserving later captured declaration ownership.

## Native capability observations

Schema-only remains a valid input observation. Newly ingested native output is experimental with ingest/render/restore supported and OCR unsupported. Runtime codec availability remains a separate registry fact. Historical version-specific validation is unchanged.
