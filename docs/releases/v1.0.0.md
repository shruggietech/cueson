# Cueson v1.0.0

Cueson v1.0.0 establishes the first stable Cue JSON and command-line contract for native SubRip and WebVTT workflows.

## Highlights

- Delivers the stable Cue JSON 1.0.0 contract with a byte-identical immutable schema in the repository, executable, and release archives.
- Provides native SubRip and WebVTT detection, bounded decoding, semantic encoding, deterministic model-driven rendering, and byte-exact source restoration.
- Converts between SubRip and WebVTT with complete deterministic loss reporting and strict rejection before output publication.
- Adds Cue JSON and native validation, privacy-bounded inspection, and deterministic completion for Bash, Zsh, Fish, and PowerShell.
- Provides a pure-Go six-target artifact matrix for Linux, macOS, and Windows on amd64 and arm64, with checksums, target-bound SPDX JSON software bills of materials, and native packaged-binary smoke evidence.
- Preserves original source bytes and unknown native content while enforcing documented input, collection, diagnostic, and conversion-loss limits.

## Boundaries

The v1 contract covers the Cueson CLI and Cue JSON Schema. Go packages remain internal, and formats beyond SubRip and WebVTT are not stable v1 capabilities. This candidate is unsigned and unattested, and the canonical `cueson.io` schema identifier is not publicly hosted.
