# Cueson v1.1.0

**Status:** Publication-ready notes for the unpublished 1.1.0 stable candidate. No tag or GitHub Release has been published.

- Add bounded UTF-8 ASS v4+/SSA v4 detection, native semantic ingest and deterministic textual model rendering, retaining ordered styles, events, overrides, karaoke, drawings and inert attachments alongside exact original source bytes.
- Complete all twelve distinct conversion directions among SubRip, WebVTT, ASS and SSA with explicit native-owner losses, deterministic target defaults, checked centisecond precision and strict/fatal refusal before output publication.
- Extend shared CLI discovery and privacy-safe inspection, hostile-input/fuzz conformance and native platform proof. Six pure-Go candidate packages include an identical immutable schema, legal files, checksums and target-bound SPDX JSON SBOMs.

The candidate accepts exact historical 1.0.0 Cue JSON using the bundled immutable schema and version-specific semantics. Every new encode uses exact 1.1.0; released v1.0.0 consumers reject this output, including documents encoded from SubRip/WebVTT. No historical-output selector is introduced. Lower-capability schema-only and complete experimental observations remain unchanged when loaded under the exact current identity.

Exact restoration reproduces original bytes; rendering and conversion do not claim byte or pixel equivalence. The bounded profile does not load external resources, execute attachments, rasterize drawings/fonts, accept legacy ASS/SSA codepages or add OCR/other format families. Packages remain unsigned and unattested. Tag/release publication and public schema/site hosting require their separate authorized outcomes; public downloads remain v1.0.0.
