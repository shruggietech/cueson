# Cueson v1.1.0

**Status:** The public v1.1.0 GitHub Release is final and independently verified.

The immutable annotated tag [`v1.1.0`](https://github.com/shruggietech/cueson/tree/v1.1.0) identifies exact revision `7ff45c1d8cd8df377e1fb568b9785286b649fd7c`. The official [Cueson v1.1.0 GitHub Release](https://github.com/shruggietech/cueson/releases/tag/v1.1.0) publishes six pure-Go archives for Windows, macOS and Linux on amd64 and arm64, six corresponding SPDX JSON SBOMs, and the six-entry [`cueson_1.1.0_checksums.txt`](https://github.com/shruggietech/cueson/releases/download/v1.1.0/cueson_1.1.0_checksums.txt) manifest.

- Adds bounded UTF-8 ASS v4+/SSA v4 detection, native semantic ingest and deterministic textual model rendering, retaining ordered styles, events, overrides, karaoke, drawings and inert attachments alongside exact original source bytes.
- Completes all twelve distinct conversion directions among SubRip, WebVTT, ASS and SSA with explicit native-owner losses, deterministic target defaults, checked centisecond precision and strict/fatal refusal before output publication.
- Extends shared CLI discovery and privacy-safe inspection, hostile-input/fuzz conformance and native platform proof. Every package includes the byte-identical immutable 1.1.0 schema and legal files, and every target has a corresponding source-bound SBOM.

Independent verification downloaded all thirteen public assets into a clean directory, matched their names, sizes and SHA-256 digests to the accepted exact-main decision package, checked the archive/checksum bijection, structurally inspected all six targets and executed the public Windows amd64 package. GitHub read-back also proved that the final non-prerelease release body and tag target matched the reviewed publication decision.

Version 1.1.0 accepts exact historical 1.0.0 Cue JSON using the bundled immutable schema and version-specific semantics. Every new encode uses exact 1.1.0; released v1.0.0 consumers reject this output, including documents encoded from SubRip/WebVTT. No historical-output selector is introduced. Lower-capability schema-only and complete experimental observations remain unchanged when loaded under the exact current identity.

Exact restoration reproduces original bytes; rendering and conversion do not claim byte or pixel equivalence. The bounded profile does not load external resources, execute attachments, rasterize drawings or fonts, accept legacy ASS/SSA codepages, or add OCR and other format families. Packages remain unsigned and unattested. The public 1.1.0 schema route and refreshed production documentation site remain tracked by issue [#67](https://github.com/shruggietech/cueson/issues/67).
