# Cueson v1.2.0

**Status:** Stable release candidate, not publicly released. Published downloads and production schemas remain v1.1.0.

- Adds optional consumer-assigned speaker attribution, separate from native subtitle speaker observations. Applications determine identifier scope and retain their chosen names, UUIDs or other bounded Unicode strings exactly.
- Adds optional declared media duration and timeline alignment. Timed speaker assignments must fit their cue and supplied media boundaries; subtitle coverage never establishes audio duration.
- Adds count-only inspection and complete native export omission reporting. Strict rendering and conversion refuse lost consumer annotations before publishing output; exact restoration preserves original source bytes.

Executable and schema identify exact `1.2.0`. Historical `1.0.0` and `1.1.0` documents remain supported through immutable local contracts; older consumers reject new output. Candidate packages target Windows, macOS and Linux on amd64 and arm64 and remain unsigned and unattested. Final publication requires fresh accepted main proof and explicit tag, release and asset authority; production hosting remains separate.

Full changelog: https://github.com/shruggietech/cueson/blob/v1.2.0/CHANGELOG.md
