# Cueson v1.2.0

**Status:** The public v1.2.0 GitHub Release is final and independently verified. Production schema and site activation remains tracked by [issue #86](https://github.com/shruggietech/cueson/issues/86) until independent live verification passes.

The immutable annotated tag [`v1.2.0`](https://github.com/shruggietech/cueson/tree/v1.2.0) identifies exact revision `6a1fd7a541767c0b19dcc10022fafc0e46903cff`. The official [Cueson v1.2.0 GitHub Release](https://github.com/shruggietech/cueson/releases/tag/v1.2.0) publishes six pure-Go archives for Windows, macOS and Linux on amd64 and arm64, six corresponding SPDX JSON SBOMs, and one six-entry checksum manifest. Every archive contains the executable, byte-identical immutable 1.2.0 schema, `LICENSE` and `NOTICE`.

## Highlights

- Adds optional consumer-assigned speaker attribution, separate from native subtitle speaker observations. Applications determine identifier scope and retain their chosen names, UUIDs or other bounded Unicode strings exactly.
- Adds optional declared media duration and timeline alignment. Timed speaker assignments must fit their cue and supplied media boundaries; subtitle coverage never establishes audio duration.
- Adds count-only inspection and complete native export omission reporting. Strict rendering and conversion refuse lost consumer annotations before publishing output; exact restoration preserves original source bytes.

Executable and schema identify exact `1.2.0`. Historical `1.0.0` and `1.1.0` documents remain supported through immutable local contracts, preserving their loaded identity and source observations. Older consumers reject new output, including output encoded from SubRip or WebVTT. The former `1.2.0-dev` identity is unsupported. No historical-output selector or migration command is introduced.

## Verification and boundaries

Fresh exact-main [release proof run 37525916113](https://github.com/shruggietech/cueson/actions/runs/37525916113) structurally verified all six archives and SBOMs, then executed that same accepted bundle on native Linux, macOS and Windows amd64 hosts. Independent publication verification downloaded all thirteen public assets anonymously and matched their names, sizes and SHA-256 digests to that accepted bundle. It rechecked all six packaged targets and executed the public Windows amd64 package. The accepted Linux/macOS execution evidence applies because those public archive bytes match; publication verification did not freshly execute the public downloads on those hosts. No arm64 execution is claimed. The [publication decision](https://github.com/shruggietech/cueson/issues/85#issuecomment-6028336030) and [completed public verification record](https://github.com/shruggietech/cueson/issues/85#issuecomment-6028397732) retain the evidence.

The immutable 1.2.0 schema is 191,170 bytes with SHA-256 `f2661a3d52effbab4a82a4d47197b5c7fae58496dc30a397ea3f2f668358b654`. It is available in the [tagged repository](https://github.com/shruggietech/cueson/blob/v1.2.0/schema/releases/v1.2.0/cueson.schema.json), release archives and executable embedding without network access. S035 prepares its canonical `/schema/v1.2.0/cueson.schema.json` route and release/speaker documentation, then continues through exact-main production deployment and independent live verification after the owner's final PR merge. GitHub publication alone does not establish that this production route is live.

Exact restoration reproduces original bytes; rendering and conversion do not claim byte or pixel equivalence. The bounded four-format profile remains unchanged. Packages are unsigned and unattested.
